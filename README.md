# 🌐 jwr12110.github.io

교육용 웹 애플리케이션 포털 사이트입니다. AI 학습 게임과 학급 관리 도구를 제공합니다.

## 📋 프로젝트 소개

이 프로젝트는 두 가지 주요 웹 애플리케이션을 포함하고 있습니다:

### 1. 🧠 AI 브레인 트레이너 (deeplearning.html)
딥러닝의 기본 원리를 게임으로 배울 수 있는 교육용 애플리케이션입니다.

**주요 기능:**
- **스테이지 1: 색깔 패턴 학습** - 데이터 학습의 기본 원리 이해
- **스테이지 2: 모양 분류하기** - 분류(Classification) 개념 학습
- **스테이지 3: 패턴 예측하기** - 예측(Prediction) 원리 체험
- 점수 및 연속 정답 시스템
- 최고 기록 리더보드

**기술 스택:**
- Vanilla JavaScript
- CSS3 (Gradient, Animation)
- HTML5

### 2. 📚 학급 자리 배치 프로그램 (seatingarrangement.html)
학급 좌석 배치를 효율적으로 관리할 수 있는 인터랙티브 도구입니다.

**주요 기능:**
- 학생 수 설정 (최대 50명)
- 랜덤 이름 생성 및 수동 입력
- 드래그 앤 드롭으로 책상 배치 조정
- 클릭으로 책상 추가/더블클릭으로 삭제
- 랜덤 자리 배정 기능
- 애니메이션 효과가 있는 배정 결과

**기술 스택:**
- Tailwind CSS
- Vanilla JavaScript
- HTML5 Drag & Drop API
- Font Awesome Icons

- 글래스모피즘(Glassmorphism) UI 디자인
